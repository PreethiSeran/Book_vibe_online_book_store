# 📚 BookVibe – Mood-Based Book Recommendation Website

**BookVibe** is a modern and responsive web application that recommends books based on the user's mood.  
It focuses on **UI/UX design principles**, color psychology, and user emotions to create a personalized and enjoyable reading experience.

---

## 🌟 Features

- 🎭 **Mood-Based Book Suggestions** – Recommends books depending on how you feel.  
- 🎨 **Clean and Aesthetic UI** – Designed with Tailwind CSS and shadcn UI for a modern and minimal look.  
- ⚡ **Fast Performance** – Built using React + Vite for speed and smooth interactivity.  
- 📱 **Fully Responsive** – Optimized for mobile, tablet, and desktop.  
- 💬 **Smooth Navigation** – Easy routing and transitions for better usability.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React (Vite)  
- **Language:** TypeScript  
- **UI Library:** shadcn/ui  
- **Styling:** Tailwind CSS  
- **Form Handling:** React Hook Form  
- **Validation:** Zod  
- **Routing:** React Router DOM  
- **Icons:** Lucide React
